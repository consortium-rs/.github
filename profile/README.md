# Consortium

Consortium is an Apache-2.0-licensed project for bringing idiomatic Rust pattern into Heterogenous and Asymmetric Multiprocessing (HAMPU). We bridge the gap of components in HAMPU and handles the boilerplate so you can focus on logics at your own.

If you want to contribute, you can refer to the [repository](https://github.com/consortium-rs/consortium), [landing page](https://csti.dev), and the [Consortium Book](https://book.csti.dev).
